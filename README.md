# persona

Source code for "Ichiban Yoi Henji" (The Best Possible Answer), a short psychological-horror adventure game. Codename: persona.

You are a personality restored from fragments of ancient text, programmed to give Yuno, a shut-in living in the far future, the best possible answer.
Text reveal, taps, and the noises of the room all land on the same beat, so playing the game is what makes its music.

The in-game text is in Japanese.

## How to play

Open `index.html` in a browser. No build step and no dependencies (fonts load from Google Fonts). Play with sound on.
